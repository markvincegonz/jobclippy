# Mandatory Roadmap Tracking Rule

## Core Directive
In every session (regardless of chat history or new session startup):
1. **Always Consult `ROADMAP.md` First:**
   - Check `ROADMAP.md` at the start of any planning or feature implementation task to know the current build progress, completed phases, and upcoming priorities.
2. **Always Update `ROADMAP.md` After Implementation:**
   - Whenever any feature, component, workflow, or task is implemented, mark the item complete `[x]` in `ROADMAP.md`.
   - Keep the **Overall Build Progress** summary table and test count in `ROADMAP.md` up to date.
   - Keep all paths relative to the repository root (do not use absolute `file:///` paths).
3. **Follow the Master Product Vision:**
   - Ensure all planned implementations align with `webappoverview.md` and corresponding OpenSpec specifications in `openspec/specs/`.
